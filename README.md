## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `POST.json` from this repository to `out/POST.json`, byte for byte. `POST.json` holds the posted meme's address on X — replace the `PLACEHOLDER` with the real post id after posting, before submitting.
